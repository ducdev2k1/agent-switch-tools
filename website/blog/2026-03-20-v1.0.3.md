**v1.0.3** adds background quota refresh every 5 minutes and auto-update infrastructure.

{/* truncate */}

## What's New

### Smart & Throttled Quota Refresh

- Background worker silently queries Usage API every 5 minutes
- Window focus triggers instant refresh
- Anti-spam throttle: max 1 API call per 2 minutes

### Profile Card UI/UX Enhancements

- Full-width usage limit progress bars
- Better refresh button alignment

### Account Type Classification Fix

- Fixed "Personal Account" mislabeling for organization accounts
- Cross-references `organizationName` and `organizationUuid` from OAuth profile

### Auto-Updater Integration

- Embedded updater pubkey and GitHub Releases endpoint in Tauri config
- App can now verify, download, and install updates automatically
