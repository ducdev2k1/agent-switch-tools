**v1.0.4** introduces a dedicated Settings page with webhook integration for centralized usage reporting.

{/* truncate */}

## What's New

### Settings Page

- New configuration hub accessible from dashboard via gear icon
- Organized into tabs: General, Webhook, About

### Webhook Integrations

- Customizable webhook URL endpoint for quota/usage reports
- Flexible triggers: on startup, on quota change, or manual
- Authentication secret support (`Authorization: Bearer` header)
- Built-in test connection utility

### General Preferences

- Theme toggle (Light / Dark / System)
- Auto-update management switch
- About section with version and license info

_v1.0.4 evolves the app into an orchestrator that binds local profiles with centralized monitoring._
