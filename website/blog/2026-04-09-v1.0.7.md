**v1.0.7** introduces one-click OAuth token refresh and fixes stale cache when switching accounts.

{/* truncate */}

## What's New

### OAuth Token Refresh

- **One-Click Refresh**: Expired profiles show a "Refresh Token" button. Click to refresh — no re-login needed.
- Works for both active and saved (inactive) profiles
- Uses `claude -p` under the hood for the same refresh flow as official CLI

### Account Switch Cache Fix

- Switching accounts no longer shows stale cached data from previous profile
- `useProfileUsage` hook detects `isActive` changes, resets stale data, and force-refreshes
- Fixed manual refresh button not passing `forceRefresh` to backend

### Backend

- New `token_refresh` module: orchestrates refresh via CLI with credential swapping
- Two new commands: `refresh_active_token` and `refresh_profile_token`

### Frontend

- New `useTokenRefresh` hook with loading state
- Inline "Refresh Token" action on expired `ProfileCard`

---

_v1.0.7 removes the need to manually re-authenticate. If a profile shows "Expired", one click brings it back._
