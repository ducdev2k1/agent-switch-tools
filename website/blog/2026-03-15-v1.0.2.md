**v1.0.2** integrates Anthropic's OAuth Usage API to fetch and display quota in real-time.

{/* truncate */}

## What's New

### Usage API Integration via Anthropic OAuth

- Rust backend natively fetches profile quotas from Anthropic's OAuth Usage API
- Smart limit buckets: Session (5h), 7-Day General, 7-Day Sonnet

### Usage Tracking Frontend

- New `UsageLimitsDisplay` component with color-coded progress bars
- Threshold alerts when nearing quota limits
- Cooldown countdowns inside Profile Card (e.g. "Resets in 1 hour")

---

_This milestone targets user awareness — preventing sudden work interruptions by delivering telemetry alerts before quotas run out._
